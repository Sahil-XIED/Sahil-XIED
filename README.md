## `03` — Featured Projects

### 🛒 CampusKart — Campus Marketplace

A campus-focused marketplace designed to help students buy and sell useful items within their community.

**Key areas:** Product listings, user verification, negotiation workflows, and a dedicated store concept for new hardware and DIY components.

**Technology:** MERN stack — MongoDB, Express.js, React, and Node.js.

[![Visit CampusKart](https://img.shields.io/badge/Explore-CampusKart-0F172A?style=for-the-badge&logo=googlechrome&logoColor=38BDF8)](https://shopcampuskart.in/)

### ✈️ SkyTech Airlines — Airline Reservation System

A Java-based airline reservation and passenger management project developed as part of an academic team project.

**Key areas:** Passenger authentication, flight search, booking management, ticketing, cancellation, and administration.

**Technology:** Java 21, JSP, Servlets, JDBC, MySQL, Maven, and Apache Tomcat 10.1.

### 📈 StockPulse — Stock Market Dashboard

A stock market dashboard project focused on presenting financial data through a web interface with interactive charts.

**Key areas:** Backend APIs, database integration, and financial data visualization.

**Technology:** Java, Spring Boot, MySQL, HTML, CSS, JavaScript, and charting libraries.

### 🎓 RepoDent — Student Management System

A student management application built to organize academic records and streamline common student management tasks.

**Key areas:** Attendance tracking, grade management, and role-based architecture.

**Technology:** C++ backend and Bootstrap-based frontend.
